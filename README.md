# BomberGuy v1.0 

## About
BomberGuy is a 2D pirate-themed Bomberman game built with Unity.

## Features
- 2D gameplay
- Demo version

## Download
Download the Windows demo ZIP in https://github.com/DuyLuAnh/Game-Development-Course-Project/releases/tag/1.0 , extract it, and run `Runner.exe`.

## Requirements
- Windows 10 or later
- 64-bit operating system

## Status
This is an early alpha demo. Bugs and incomplete features may exist.
